# AP01.2: Plan spelling review

Package: [AP01: Pascal conventions](README.md)

Status: complete.

## Result

The [spelling rules](spelling-review.md) apply across package and work-package
files. Type applications use `of`; routine type-parameter declarations use
angle brackets. Parameters are individually typed and separated by `;`, while
call arguments use `,`. Completed syntax and planned syntax are distinguished.

## Validation

Positive planning examples use the recorded spellings. Rejected examples are
explicitly identified, and unresolved language rules stay with the owning AP.
