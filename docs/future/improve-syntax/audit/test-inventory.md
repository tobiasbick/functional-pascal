[source audit](source-map.md). It contains executable-test entry points and
representative target test designs. Existing tests were inspected, not executed;
target cases below are not implemented tests. Stage completion remains in the
[steering plan](../README.md).

## Target cases to turn into executable tests

Each row describes behavior, not a helper implementation. Positive and negative
cases should run through parser/sema plus compiler/VM or the CLI wherever effects
are observable. Use source-embedded Rust cases for malformed syntax. Valid FPAS
regressions belong in the existing themed suite; file-producing cases use
`.temp-data/`.

| Contract family | Positive case and expected result | Negative / interaction case and expected result |
|---|---|---|
| Diagnostics | The same parse/runtime error in text and JSON has the same code, phase and source; supplementary Unicode before an error yields scalar-based start and exclusive end coordinates. | Missing file/no location yields null; imported-unit error retains its source. Program stderr containing JSON-like text is a program-output event, never a diagnostic. All four commands preserve exit status and emit no progress/summary contamination. |
| Grammar | Nest each named block inside another, use null for empty action bodies, anonymous routines as arguments and expressions before comma/parenthesis; format twice identically. | Missing/mismatched closer, end-dot, extra empty statement, omitted final semicolon, grouped declarations, comma formals, and else-if with only one closer yield canonical hints without recovery loops. |
| Imports/names | Alias-qualified exported type, constructor and routine work; case-insensitive access remains stable when another import is added. | Plain/wildcard imports, secondary full-name access, two aliases for one unit, alias shadowing, type/routine collision and inaccessible fields are rejected. |
| Types/initializers | Forward type references with finite collection/variant recursion work; initializer side effects occur once in dependency/declaration order. | Alias cycles, direct infinite records, recursive variants without a finite value, and initialization dependency cycles fail. Later assignments do not rescue missing local inference. |
| Bindings/static contexts | Local const from an ordinary call runs once; var can be reassigned; an annotated empty collection resolves. | Const reassignment, absent top-level type, underdetermined empty collection and computed value in a static bound/label fail at the relevant subexpression. Pure calls remain non-static. |
| Value/resource copies | Copy record(array(dict)), mutate a nested copy and preserve the original; copied channel handles communicate with the same resource. | Resource/task/callable containment is detected through record, variant, collection and distinct wrappers for purity/equality/transfer. Const permits a resource action but forbids replacing its field. |
| Captures/loops | Two copies of a stateful closure share updates; each loop iteration's immutable captured value stays distinct. | Capture a var parameter, spawn a mutable-capture closure directly or through a container/nested closure: reject. Ordinary same-task closure use remains valid. |
| Invocation | Returned, indexed, selected and record-field callables execute; a side-effect trace is target, argument 1, argument 2, body, each once. | Named routine/variant arguments, procedure in value position, type/routine ambiguity and hidden receiver expectations fail. Parameter names do not change compatible callable types. |
| Construction/update | Supplied fields evaluate in written order, then omitted defaults in declaration order on every construction; update evaluates base then replacements once and preserves original. | Duplicate/unknown/inaccessible fields, omitted required field, default reading another field/mutable outer binding or calling an ordinary function fail. Private defaulted fields still prevent outside construction. |
| Generics | Nested Box/Option/Result data and multiple instantiations work; a generic routine assigned to an expected concrete function type instantiates. | Unresolved constructor parameter, no expected type for generic routine value, unsupported dictionary key, failed Equatable/Comparable constraint and alternate type-argument spelling fail. |
| Equality | Arrays compare ordered elements; dictionaries with reverse insertion order and equal mappings compare equal. | Nested resources/callables/tasks reject equality; arrays/records receive no ordering. Check scalar and nested NaN/signed-zero consistency and generic equality-only constraints. |
| Decisions/patterns | Nested variant patterns bind const names, guards see bindings, one scrutinee and one chosen expression execute; open scalar statement may do nothing. | Guard-only coverage, enum catch-all, missing variant/else, inconsistent grouped bindings, duplicate/unreachable arm and incompatible expression branch types fail. Enum extension exposes missing branches. |
| Boolean/evaluation | Comparisons bind above not and logical operators; and/or skip the right operand, xor evaluates it. | Mixed logical chains and comparison chains fail with grouping guidance. Migration preserves side-effecting middle operands and evaluation count. |
| Numeric | Test i64 endpoints, checked ordinary arithmetic, real infinities/NaNs, bit-pattern shifts 0 and 63 and zero-fill right shift. | Overflow, integer zero division, invalid conversion and shifts -1/64 fail; static invalid operations fail before execution. Run debug/release and folding/non-folding paths. |
| Explicit mutation | Indirect/imported var call and forwarded reborrow mutate immediately; earlier read-only snapshot remains unchanged. | Same-root fields/indices, callback alias access during exclusive use, alias resize during path evaluation, const/temporary roots and missing var markers fail. A later argument failure or callee panic retains earlier completed effects. |
| Purity | Pure callback passed to ordinary callable parameter, local mutable accumulator and resource-free generic instantiation work. | Ordinary-to-pure conversion, external mutable read/write, resource use, ordinary call, var parameter, mutable capture and returned stateful closure fail. Defaults and collection callbacks use the same checker. |
| Result/discard | Compatible try forwards Result.Error; discard evaluates an ordinary function result once. | Unused value, discard of procedure/task/nested task container, incompatible try and panic-as-Result assumptions fail. |
| Scope ownership/escape | Both go forms inside an explicit scope; synchronous proven non-retaining helper; repeated Wait returns copies of one completed result. | Spawn outside a lexical scope, borrowed caller scope, task return/channel/resource/global/container escape, unknown retaining callback and unobserved function result fail. Barrier alone does not observe results. |
| Scope exit | Normal exit joins; return/break/continue/try crossing a boundary cancel and join; inner-loop break does not cancel the enclosing scope. | Block children on channels/network, trigger body/child panic and nested cancellation; no child survives completed exit. Preserve primary panic and secondary diagnostics. Returned Result.Error alone does not cancel siblings. |
| Domains | Distinct construction/unwrapping explicit; singleton/range endpoints valid; subrange arithmetic widens and membership does not narrow. | Swapped distinct identities, implicit narrowing, invalid bounds and adjacent out-of-range values fail; wrapping a resource preserves all restrictions. |
| Contracts | Ordered clauses on named/anonymous/indirect calls; postconditions see exit var snapshots and clause-local result, including Result.Error returns. | False/panicking clause reports bounded values/location without invoking user display code. No ensures after panic/cancellation/failed cleanup; same enforcement in release; result binder cannot escape clause. |

## Verification execution boundary

No target syntax fixtures are added while the compiler still implements the old
language. During implementation, add each target row's cases with its owning
slice, migrate old assertions explicitly, and run the shared
[required checks](../verification.md#required-checks-for-implementation).
Use the actual bundled runner as well as in-process helpers for stream/exit tests.
Do not mark any implementation stage complete from this inventory alone.
