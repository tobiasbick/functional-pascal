# Getting started

Introduction, first programs, and reserved keywords.

To create a runnable project instead of a standalone source file:

```sh
fpas init project hello
fpas run hello/hello.fpasprj
```

See [Initializing projects and workspaces](../program-structure/initializing.md)
for library and workspace scaffolds, safe retries, dry runs, and JSON output.
