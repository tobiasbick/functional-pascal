# Hello world

```pascal
program Hello;

uses Std.Console as Console;

begin
  Console.WriteLn('Hello, World!');
end program;
```

Run with `fpas run` from a project directory that includes this program, or pass the `.fpas` file path directly (`fpas run hello.fpas`).
