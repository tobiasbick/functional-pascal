# Constants

Constants are declared with `const` and `:=`. Must have a value known at compile time:

Formal syntax: [`grammar.ebnf`](../../../specs/grammar.ebnf) (`const_decl`).

```pascal
const
  Pi: real := 3.14159265;
  MaxSize: integer := 1024;
  Greeting: string := 'Hello';
```
