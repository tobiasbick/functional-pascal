# FPAS user interfaces

GUI and TUI applications render a model and send typed messages to an update function. Choose the handbook for the host you want to build.

| Chapter | What it covers |
| --- | --- |
| [Layout](layout/README.md) | Compose containers, size children and adapt the view to the viewport. |
| [Graphical UI](gui/README.md) | Open a desktop window and explore CUI widgets with screenshots, examples and interaction details. |
| [Terminal UI](tui/README.md) | Compose cell-based panels and use the controls demonstrated in the terminal gallery. |
| [Model–View–Update](mvu/README.md) | Share application logic, run effects and compose larger views from independently updated parts. |

The [shared widget reference](widgets.md) lists the supported host profiles, layout rules, themes and widget options.
