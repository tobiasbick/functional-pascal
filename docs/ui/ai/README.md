# AI

The gallery shows a sample conversation, tool results and a research plan.
Use these widgets to display application data and handle the resulting
messages in your update. These widgets require the GUI host.

| Widget | When to use it |
| --- | --- |
| [Reasoning panel](reasoning.md) | Group supplied reasoning text in an expandable panel. |
| [Tool call](tool-call.md) | Display a tool's status and expandable input and output. |
| [Agent plan](agent-plan.md) | Show ordered agent steps and their state. |
| [Agent status](agent-status.md) | Show the agent's current activity and elapsed time. |
| [Source list](source-list.md) | Display cited sources as horizontally scrolling cards. |
| [Citation](citation.md) | Show an inline source reference and optional preview. |
| [Model picker](model-picker.md) | Choose a model from names, descriptions and badges. |
| [Prompt suggestions](prompt-suggestions.md) | Offer suggested prompts that fill the draft. |
| [Response actions](response-actions.md) | Offer copy, regenerate, vote and share below an answer. |
| [Context meter](context-meter.md) | Show the fraction of context used and its breakdown. |
