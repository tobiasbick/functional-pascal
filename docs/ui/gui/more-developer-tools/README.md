# More developer tools

The gallery combines test results, source reports, HTTP request controls
and status views. Each widget draws the data supplied by the application.
These widgets require the GUI host.

| Widget | When to use it |
| --- | --- |
| [Test explorer](test-explorer.md) | Inspect test results, filter suites and request test runs. |
| [Stack trace](stack-trace.md) | Show exception frames, library groups and nearby source. |
| [Blame](blame.md) | Show the last revision associated with each source line. |
| [Coverage](coverage.md) | Browse coverage by folder and file and sort by metrics. |
| [Regex tester](regex-tester.md) | Edit a pattern and inspect matches on sample text. |
| [HTTP request bar](http-request-bar.md) | Collect a request method and URL with Send and Cancel actions. |
| [HTTP response status](http-response-status.md) | Summarize an HTTP result's code, time and size. |
| [API explorer](api-explorer.md) | Browse endpoint summaries and parameter definitions. |
| [Feature flags](feature-flags.md) | Edit toggles and rollout shares for several environments. |
| [Uptime bars](uptime.md) | Show daily availability for each service. |
| [Time histogram](time-histogram.md) | Show stacked counts over time and select a range. |
