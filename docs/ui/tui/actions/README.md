# Actions

| Widget | When to use it |
| --- | --- |
| [Button](button.md) | Run a command such as saving the current draft. |
| [Dropdown menu](dropdown-menu.md) | Group related commands behind one button. |
| [Segmented control](segmented-control.md) | Select a single view or filter. |
| [Toggle group](toggle-group.md) | Set independent options or choose one exclusive option. |
