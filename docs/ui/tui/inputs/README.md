# Inputs

| Widget | When to use it |
| --- | --- |
| [Text field](text-field.md) | Edit one line of model-owned text. |
| [Search field](search-field.md) | Edit and clear a query. |
| [Number field](number-field.md) | Type or step through a bounded number. |
| [Text area](text-area.md) | Edit descriptions, notes or other multiline text. |
| [Select](select.md) | Choose one option, optionally filtering a longer list. |
| [Multi-select](multi-select.md) | Search a list and toggle several choices. |
