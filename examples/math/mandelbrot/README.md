# Mandelbrot Showcase

Fullscreen terminal Mandelbrot explorer (`Std.Console`). Multi-unit `.fpasprj`.

Demonstrates: units, record methods/statics/`Zoom` property, postfix chaining
(`Z.Sq().Add(C)`), fork-join row tasks, truecolor cells, raw-mode events.

## Run

```sh
fpas run examples/math/mandelbrot/mandelbrot.fpasprj
```

## Controls

Arrow keys pan; `+`/`-` and wheel zoom; click centers; middle-click/`R` reset;
`PageUp`/`PageDown` iterations; `1`/`2`/`3` palettes; `Esc` quits.
