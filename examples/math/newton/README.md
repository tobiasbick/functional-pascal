# Newton fractal

Fullscreen terminal Newton basins for `z^3 - 1 = 0` (`Std.Console`).

Colors by attracting root (red / green / blue) with shade from iteration count.

## Run

```sh
fpas run examples/math/newton/newton.fpasprj
```

## Controls

Arrows pan; `+`/`-` and wheel zoom; click centers; `PageUp`/`PageDown`
iterations; `R` reset; `Esc` quits.
